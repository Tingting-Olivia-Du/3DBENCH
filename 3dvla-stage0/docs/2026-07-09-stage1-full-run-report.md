**显存压测**（最坏情形 = 64 条纯 generic3d 32 帧记录，140G 卡）：bs4 OOM（140.6G 后爆）；

**loss 行为**：逐点方差天然巨大（σ≈0.39；单点 = 2 条对话的裸 loss，各切片监督 token 数差百倍，

## 3. T7 热重启瞬态（V 形坍缩）——诊断记录

**现象**：M1-T7 在 30K→60K 间从 83.2 掉到 56.4，90K 恢复到 87.7（V 形）；同期 LIBERO-T7 稳定。

**取证**：187 题中 132 题答案改变；退化样本**清一色**输出同一刷板答案
`right 1.1; down 1.1; backward 1.1 cm`（各分量同为 1.1 的近静止先验，对应训练数据中 ~10% 的
"无显著运动"负样本），而 30K 对同题能给出贴合 GT 的逐样本估计（如 `up 4.8; forward 13.1` 精确命中）。

**结论**：热重启瞬态——优化器动量清零 + lr 回峰，最新装入、最脆弱的能力轴被暂时冲掉、
退守到安全先验答案；~30K 微步内自愈并反超。**实践指引**：
① 训练中途尽量不做热重启（none 跑已按此执行）；
② 能力探针的灵敏度远高于聚合 loss（此事件在 loss 曲线上不可见）；
③ 若必须重启，重启后的第一个探针点不能作为该 ckpt 的能力结论。

## 5. RefCOCO-val 遗忘审计

协议：REC 方向（LLaVA 原生措辞、无前言），n=500，双方 convention-oracle 计分
（{[0,1], [0,1000], [0,2000), 绝对像素} 择优）。

| 模型 | 输出方言分布 | oracle acc@IoU.5 |
|---|---|---|
| base | 497/497 全部 [0,1000]（其原生制） | **92.4** |
| full-final | 500/500 全部 [0,1]（受训方言） | **80.2** |

**−12.2 分。已排除的解释**：两位小数量化天花板 = 100%（把 GT 舍入到 0.01 粒度在同一 500 样本上
零精度损失；该抽样无 <2% 面积的微小框）→ 不是格式固有损耗。

**成立的解释**：模型把 LLaVA 式定位分布**连同其精度画像**整体采纳（80.2 恰在 LLaVA 系模型
RefCOCO REC 的典型区间），替换了 Qwen 原生更强的 [0,1000] 定位行为。定性：**方言采纳型回退**，
非灾难性遗忘（零串台、解析 100%、域内 T1 strict 89.6/99.6 远超 base 的 oracle 上界）。

**配方启示（留给 v2，本变体家族保持配方冻结以保内部可比）**：防遗忘切片的方言应选骨干
**自身最强**的原生约定（Qwen = [0,1000] 整数），或在 general 切片混入原生制定位数据。

"训练措辞 + 冲突约定"组合：**方言绑定在题型上，而非只绑定在前言上**。计入论文
格式完整性一节；对部署的含义：换约定必须换措辞，或在部署侧固定我们的前言。
