# VLA Ablation Configs — FMDecoder (Flow Matching) variants

Flow-matching action-head variants of `configs/vla_ablation/`. Same backbones,
model paths, data, norm settings and training strategies; the `act_head` is
`FMDecoder` (DiT + layer-wise cross-attention) instead of `FCDecoder`.

- `fwd_pred_next_n`: 4 (action chunk)
- DiT `cross_attention_dim`: 2048 (= Qwen2.5-VL-3B hidden size)
- DiT `num_layers`: 12 (<= 36 backbone layers)

Requires the FMDecoder support added to `RoboQwen25VL.forward_continuous`.
